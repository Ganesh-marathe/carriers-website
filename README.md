# CareerConnect — Career Platform

An industry-level SaaS career platform built with HTML, CSS, JavaScript, and Vite.

## 🚀 Technology Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- Vite
- Git & GitHub

carriers-website/

## 💻 Installation

Clone the repository:

```bash
git clone https://github.com/Ganesh-marathe/carriers-website.git
```

Navigate to the project:

```bash
cd carriers-website
```

Install dependencies:

```bash
npm install
```

## ▶️ Run Development Server

```bash
npm run dev
```

Open the local URL provided by Vite, usually:

```text
http://localhost:5173
```

## 🏗️ Production Build

```bash
npm run build
```
